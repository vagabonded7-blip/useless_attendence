# Wokwi kaatt motor

1. Open https://wokwi.com/projects/new/arduino-uno.
2. Replace the generated `sketch.ino` and `diagram.json` with the files in this folder.
3. Start the simulation and open the Serial Monitor.
4. Copy the project URL into `WOKWI_PROJECT_URL` in `attendence.py`.

The attendance app opens that project after a phone number is entered and shows the same message while waiting:

`Ain't it hot, have some kaatt`
